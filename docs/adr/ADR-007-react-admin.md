# ADR-007: Admin console in React, not Filament or Nova

**Status:** Accepted (approved 22 Nov 2026)

## Context
Every screen must follow the locked design (theme C) and the same component library as the provider portals.

## Decision
The Super Admin console is part of the React web app, using the same components, routing and API.

## Consequences
Slightly more work than a generated admin, but one consistent product.
